# VinFastOwners.org — Website Updates & Resources Summary

*Prepared: March 1, 2026 — For Newsletter Production*

---

## The Big Picture

The Association of VinFast Owners (AVO) website — [vinfastowners.org](https://vinfastowners.org) — has undergone a **complete V2 redesign** and now serves as a comprehensive hub for VinFast EV owners across the United States and Canada. The site features **16 production pages**, is **fully bilingual (English/French)**, and includes **dark mode**, all built with zero external frameworks — just clean HTML, CSS, and JavaScript.

AVO is an **independent, member-governed organization** — not affiliated with or sponsored by VinFast Auto Corporation.

---

## V2 Design Overhaul (Completed February 2026)

The entire site was rebuilt from the ground up with a modern design system:

- **Glass-effect navigation bar** with scroll-aware behavior and a progress indicator
- **Dark mode** with automatic system preference detection and a manual toggle — persists across sessions
- **Fully bilingual (EN/FR)** — every piece of text, including tooltips, form labels, and alt text, is available in both English and French with a one-click language toggle
- **Mobile-first responsive design** tested across all breakpoints (320px to 1440px)
- **WCAG AA accessibility compliance** in both light and dark modes
- **Schema.org structured data** for improved search engine visibility
- **VinFast-branded color palette** with CSS design tokens throughout
- **No tracking scripts, no cookies, no analytics** — privacy by design
- **No external dependencies** — no jQuery, Bootstrap, or external fonts

## Resources Now Available

### 1. Recalls & Safety Tool
**Page:** [vinfastowners.org/recalls.html](https://vinfastowners.org/recalls.html)

A **live recall search tool** powered by the official NHTSA API. Owners can:
- Search US recalls by vehicle model (VF6, VF7, VF8, VF9) and model year (2023–2026)
- Access **Transport Canada VRDB** links for Canadian recalls (English and French)
- Look up recalls by VIN via NHTSA's official tool (AVO does not collect or store VINs)
- Learn the difference between Safety Recalls, Technical Service Bulletins (TSBs), and Service Campaigns
- Follow a clear 5-step guide on what to do when a recall is issued

---

### 2. Trip Data & Charging Insights
**Page:** [vinfastowners.org/trip-data.html](https://vinfastowners.org/trip-data.html)

A **community-driven data collection and visualization tool** with three tabs:

- **Trip Data Submission** — Log your trip with vehicle model, battery size, distance, efficiency, drive mode, regen braking setting, weather/temperature, highway/city split, HVAC usage, and passengers
- **DCFC Charging Submission** — Log DC fast charging sessions with network, location (region only), start/end SOC, peak charge rate, and session rating
- **Data Insights** — Five interactive charts (powered by Chart.js):
  - Average Efficiency by Vehicle Model
  - Efficiency by Drive Mode
  - Efficiency vs. Temperature
  - DCFC Peak Charging Speed by Network
  - DCFC Charging Curve by Starting SOC

All submitted data is stored publicly and transparently.

### 7. Issue Reporting via GitHub
**Page:** [vinfastowners.org/report-issue.html](https://vinfastowners.org/report-issue.html)

A **transparent, public issue tracking system** using GitHub Issues. Members can report:

1. Vehicle Issues (charging, infotainment, ADAS, motor)
2. App Issues (VinFast mobile app)
3. Service Issues (RepairWise, NAPA NexDrive, dealership)
4. Feature Requests (vehicles, app, or AVO website)
5. Request Escalation (ask the AVO board to escalate to VinFast Corporate)
6. Quick Questions (redirects to Discord)

All reports are public, searchable, and community members can vote with reactions and track progress.
